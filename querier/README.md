## Description

The `querier` program processes queries on a given dataset of crawled documents. It utilizes a pre-built index generated by an indexer program to locate and rank documents that match the user’s query. The program supports boolean operators like `AND` and `OR` for query refinement and outputs document URLs, document IDs, and relevance scores based on word occurrences in each document.

## File Structure

- **querier.c**: Main C program that reads user queries, searches the index, and produces relevant document results.
- **querier.h**: Header file defining functions and structures used in `querier.c`.
- **Makefile**: Contains commands to compile the querier program.
- **README.md**: This file, providing an overview and instructions for using `querier`.
