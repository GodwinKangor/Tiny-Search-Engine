# Crawler Module

## Overview
The `crawler` is the first component of the Tiny Search Engine (TSE) project. It is responsible for crawling the web starting from a given seed URL, fetching pages, scanning for links, and saving the pages to a designated directory. The crawler explores internal links only, up to a specified maximum depth.

The pages fetched and saved by the `crawler` will be used in the later stages of the search engine, such as indexing and querying.
